We study how users of anonymous platforms can be profiled. We showed how to infer the nationality and geolocation of Tor users {% cite la2019nationality %} and how to link Dark Web aliases to Reddit identities through native-language identification, stylometry, and posting times {% cite arabnezhad2020light %}. Related work covers authorship attribution {% cite bacciu2019cross %} and machine-translation detection with source-language identification {% cite la2023translated %}.

Funding: *From the Dark Web to Reddit* (Avvio alla Ricerca 2019, PI).
